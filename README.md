# 📝 Full-Stack Notes App

A simple  full-stack Notes Application developed to understand the complete workflow of building a modern web application. The project demonstrates how the frontend, backend, and database interact through REST APIs while implementing essential CRUD (Create, Read, Update, Delete) operations.

This application was built as a learning project to gain hands-on experience with full-stack development, including API design, database integration, state management, and client-server communication.

## 🚀 Features

* Create new notes
* View all saved notes
* Update existing notes
* Delete notes
* Clean user interface
* RESTful API integration
* Persistent data storage using MongoDB

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Bushendra/NotesApp.git
```

### Navigate to the project

```bash
cd Notes
```

### Install backend dependencies

```bash
cd backend
npm install
```

### Install frontend dependencies

```bash
cd ../frontend
npm install
```

---

## ▶️ Running the Application

### Start the backend

```bash
cd backend
npm run dev
```

### Start the frontend

```bash
cd frontend
npm run dev
```

Open your browser and visit the URL displayed by Vite (commonly `http://localhost:5173`).
